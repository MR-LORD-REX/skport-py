# skport-py

An async Python client for SKPORT and Endfield. Fetch public profiles and
character builds, access token-bound owner data, and calculate static stats
using cached Enka assets. SKPORT artwork is the default.

Requires Python 3.11 or newer.

```console
pip install skport-py
```

Read the [documentation](docs/overview.md) for setup, examples, configuration and
the API reference. The responsive documentation website is in `docs/`, ready
for [GitHub Pages](docs/maintainers/hosting.md).
